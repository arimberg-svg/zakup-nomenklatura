01 Какой путь выбратьОдна позиция, линейка или сайт ▾

Номенклатура живёт в 1С. Карточка на сайте — это отдельный контур QUAD. Сначала заводим товар в 1С, потом (если он должен быть онлайн) заливаем в QuadCRM.

02 Правильное наименованиеSkillCup [2589] ▾

Наименование — то, по чему коллеги ищут товар в 1С и печатают документы. Одинаково в «Рабочем наименовании» и в «Наименовании для печати».

Тип товара + марка / бренд + модель + 1–3 основные характеристики
1. Что должно включать наименование

Тип — что это за товар. Марка — как на упаковке. Модель — заводской индекс. Характеристики — только то, без чего позицию не отличить.

03 Заливка поштучно в 1СSkillCup [2286] ▾

Этот путь — когда позиций мало и каждую карточку заполняете руками. Раскройте шаг — внутри скриншот из 1С.

На руках до входа в 1С Артикул · наименование по формуле · штрихкод · основной поставщик.
1. Какие данные нужны

До входа в 1С соберите: артикул, наименование по формуле, штрихкод, основного поставщика.

2. Открыть справочник номенклатуры

Путь: 1С → НСИ → «Номенклатура».

3. Создать группу (если нужно) и карточку

Зайдите в нужную группу. Новую группу создавайте только если её ещё нет, затем «Создать».

4. Заполнить карточку товара

Сначала «Показать все». Дальше: штрихкод → рабочее наименование → наименование для печати → артикул → вид «Товар» → основной менеджер (у руководителя) → единица «штуки» → марка/бренд.

5. Основной поставщик на вкладке min–max

Вкладка «min – max: помощник закупок». В колонке «Основной поставщик» выберите контрагента, у которого покупаем товар.

Не закрывайте карточку без поставщика Вкладка «min – max: помощник закупок». Без поставщика позиция потом теряется в закупке.
04 Массовое заведение в 1СSkillCup [695] / [2593] ▾

Когда есть готовый список и нужно завести линейку целиком. Раскрывайте шаги по порядку — 15 экранов из SkillCup.

Модуль массовой заливки Скачать: https://disk.yandex.ru/d/ja5BBRSIcqRyJw
После загрузки обязательно проставьте бренд всем новым позициям — модуль сам это не делает.
1. Наличие списка товаров

Подготовьте список: наименование по формуле, штрихкод, при наличии — артикул.

2. Раздел «Номенклатура»

В 1С откройте раздел «Номенклатура».

3. Выбрать место для новых товаров

Встаньте в ту ветку справочника, куда нужно положить новые товары.

4. Создать группу — только если нужно

Новую группу создавайте только если подходящей ещё нет.

5. Задать наименование группы

Имя группы — как вы реально ищете этот ассортимент в 1С.

6. Скачать модуль массовой заливки

Скачайте модуль: https://disk.yandex.ru/d/ja5BBRSIcqRyJw

7. Настроить колонки в модуле

В модуле настройте колонки под ваш файл.

8. Загрузка номенклатуры и штрихкода

Загрузите в модуль наименование и штрихкод.

9. Сопоставить графы с колонками списка

Сопоставьте графы модуля с колонками списка один в один.

10. Единица измерения — штуки

Единица измерения — штуки, если нет отдельного указания.

11. Кнопка «Загрузить»

Когда все поля заполнены — кнопка «Загрузить».

12. Проверить результаты модуля

Проверьте протокол: сколько создано, нет ли ошибок и дублей.

13. Закрыть модуль и открыть группу

Если ошибок нет — закройте модуль и зайдите в группу, куда заливали товары.

14. Выделить все товары: Ctrl + A

Кликните на любой новый товар и выделите все сочетанием Ctrl + A.

15. Проставить марку / бренд

Массово проставьте марку / бренд. Модуль сам бренд не ставит.

После заливки проверьте 2–3 карточки Наименование, штрихкод, единица, бренд, правильная группа.
05 Заливка в QUAD / сайтSkillCup [1085] ▾

QuadCRM — контур сайта. Сюда товар попадает, если позиция должна продаваться онлайн. 29 шагов: выберите нужный блок.

Логика QUAD Ищем в каталоге и прайсе → не создаём дубль → описание, фото, габариты, характеристики → выгрузка на сайт (товар, картинки, остатки, габариты).
1. Список товаров для заливки

Подготовьте список позиций, которые должны появиться на сайте.

2. Работа в QuadCRM

Откройте QuadCRM.

3. Раздел «Прайсы»

Раздел «Прайсы» — отсюда берём данные поставщика.

4. Проверка товара в основном каталоге

Сначала поиск в основном каталоге. Если товар уже есть — не заводите второй раз.

5. Сопоставление товара

Сопоставьте позицию прайса с карточкой каталога.

6. Сопоставление товара, часть 2

Проверьте совпадение наименования, артикула, бренда.

7. Сопоставление товаров, часть 3

Если сомневаетесь — лучше уточнить, чем склеить разные товары.

8. Добавление товара из прайс-листов

Товар из прайса добавляйте, только когда сопоставление не нашло карточку.

9. Добавление нового товара

Новую карточку заполняйте теми же правилами наименования, что и в 1С.

10. Добавление нового товара, продолжение

Не оставляйте пустые обязательные поля.

11. Редактирование товаров

После создания сразу откройте карточку на редактирование.

12. Обновление остатков

Обновите остатки, иначе на сайте будет «нет в наличии» или неверное количество.

13. Редактирование после остатков

Проверьте, что правите именно ту позицию, которую только что завели.

14. Описание товара

Описание — для сайта, понятным языком.

15. Редактирование описания

Отредактируйте текст, уберите дубли и мусор из прайса.

16. Габариты товаров

Габариты нужны для доставки.

17. Добавление фотографий

Фото: рабочий ракурс, без водяных знаков чужого магазина.

18. Редактирование характеристик

Характеристики должны совпадать с упаковкой.

19. Выгрузка характеристик

При необходимости выгрузите характеристики, чтобы править пакетом.

20. Комплектация

Комплектация — что входит в набор. Не путайте с сопутствующим товаром.

21. Ещё правка характеристик

После правки характеристик сохраните карточку.

22. Загрузка характеристик из таблицы

Большой объём удобнее грузить из таблицы.

23. Загрузка характеристик из Excel

Файл Excel должен совпадать с шаблоном QUAD.

24. Выгрузка изображений на сайт

Картинки выгружаются отдельно от текста карточки.

25. Выгрузка товара на сайт

Выгрузка товара на сайт — финальный шаг по самой карточке.

26. Выгрузка товара, часть 2

Проверьте статус выгрузки на следующем экране.

27. Выгрузка товаров, часть 3

Если позиций несколько — дождитесь окончания пакета.

28. Выгрузка остатков

Остатки выгрузите отдельно.

29. Выгрузка габаритов

Габариты тоже выгружаются отдельной операцией.
