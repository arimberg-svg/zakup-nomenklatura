02 Правильное наименованиеФормула имени товара в 1С ▾

Наименование — то, по чему коллеги ищут товар в 1С и печатают документы. Одинаково в «Рабочем наименовании» и в «Наименовании для печати».

Тип товара + марка / бренд + модель + 1–3 основные характеристики

1. Что должно включать наименование

Тип — что это за товар. Марка — как на упаковке. Модель — заводской индекс. Характеристики — только то, без чего позицию не отличить.

2. Пример правильного наименования

Пример: было «КЗВ-180 (180 мм) Кожух защитный вытяжной „ДИОЛД“». Надо: «Кожух защитный вытяжной ДИОЛД КЗВ-180, 180 мм».

03 Заливка поштучно в 1СОдна карточка руками ▾

Этот путь — когда позиций мало и каждую карточку заполняете руками. Раскройте шаг — внутри скриншот из 1С.

На руках до входа в 1С Артикул · наименование по формуле · штрихкод · основной поставщик.
1. Какие данные нужны

До входа в 1С соберите: артикул, наименование по формуле, штрихкод, основного поставщика.

2. Открыть справочник номенклатуры

Путь: 1С → НСИ → «Номенклатура».

3. Создать группу (если нужно) и карточку

Зайдите в нужную группу. Новую группу создавайте только если её ещё нет, затем «Создать».

4. Заполнить карточку товара

Сначала «Показать все». Дальше: штрихкод → рабочее наименование → наименование для печати → артикул → вид «Товар» → основной менеджер (у руководителя) → единица «штуки» → марка/бренд.

5. Основной поставщик на вкладке min–max

Вкладка «min – max: помощник закупок». В колонке «Основной поставщик» выберите контрагента, у которого покупаем товар.

Не закрывайте карточку без поставщика Вкладка «min – max: помощник закупок». Без поставщика позиция потом теряется в закупке.
04 Массовое заведение в 1СЛинейка через модуль в базе ▾

Когда есть готовый список и нужно завести линейку целиком. Раскрывайте шаги по порядку.

Модуль уже в 1С:Торговля У сотрудников отдела закупа модуль массовой заливки установлен в базе — открывайте его из 1С, отдельно скачивать не нужно.
1. Наличие списка товаров

Нужен список: счёт, спецификация или таблица. Обязательно три колонки: артикул, наименование, штрихкод.

2. Раздел «Номенклатура»

1С → «НСИ и администрирование» → «Номенклатура».

3. Выбрать место для новых товаров

Справа иерархия групп. Выберите группу, куда пойдут новые товары, либо готовьтесь создать новую.

4. Создать группу — только если нужно

Если группы нет: в дереве справа ПКМ по разделу → «Создать группу». Лишние папки не плодим.

5. Задать наименование группы

Имя группы — название поставщика, бренда или категории товара.

6. Открыть модуль массовой заливки в 1С

Модуль уже установлен в 1С:Торговля у сотрудников отдела закупа — откройте его из базы, скачивать ничего не нужно.

7. Настроить колонки в модуле

В модуле: «Каталог» — файл со списком; «Группа номенклатуры» — куда создавать; вид — «Товар»; НДС — «22%»; путь к логу не заполняем.

8. Загрузка номенклатуры и штрихкода

Основные параметры: файл со штрихкодами, созданная группа, вид «Товар», НДС всегда 22%, путь к логу пустой.

9. Сопоставить графы с колонками списка

Вкладка «Параметры чтения»: сопоставьте колонки Excel (артикул, наименование, штрихкод) и укажите, с какой по какую строку идут товары. Шапка в диапазон не входит.

10. Единица измерения — штуки

Вкладка «Статические параметры»: единица измерения — «штуки».

11. Кнопка «Загрузить»

Кнопка «Загрузить». Файл Excel со списком должен быть закрыт, иначе модуль не запустится.

12. Проверить результаты модуля

Смотрите «Всего создано» и вкладку «Не созданные». Если такой артикул уже есть, новую карточку модуль не создаст.

13. Закрыть модуль и открыть группу

Модуль больше не нужен — закройте. Откройте группу номенклатуры, куда легли товары.

14. Основной поставщик всем выделенным

Клик по любой строке, Ctrl+A, «Изменить выделенное». Найдите «Помощник закупок. Основной поставщик», поставьте галочку и выберите контрагента.

15. Проставить марку / бренд

Снова Ctrl+A → «Изменить выделенное» → строка «марка/бренд», галочка, выбрать бренд. Если бренда нет — «Создать».

Три вещи, без которых модуль ломается Файл Excel со списком должен быть закрыт. НДС в модуле всегда 22%, путь к логу пустой. Если артикул уже есть в 1С — карточка не создастся, смотрите вкладку «Не созданные».
После заливки Ctrl+A → «Изменить выделенное»: сначала основной поставщик, затем марка/бренд. Нет бренда в списке — «Создать». Проверьте 2–3 карточки: наименование, штрихкод, единица, группа.
